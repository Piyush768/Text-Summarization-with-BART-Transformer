# Text-Summarization-with-BART-Transformer

### **Overview**  
This project focuses on **Text Summarization** using **Natural Language Processing (NLP)** techniques. It supports both **extractive** (selecting key sentences) and **abstractive** (generating new text) summarization approaches. The model can be used **with fine-tuning** (custom-trained on specific datasets) or **without fine-tuning** (using pre-trained models).  

### **Features**  
✅ **Extractive & Abstractive Summarization**  
✅ **With Fine-Tuning**: Custom-trained model for domain-specific summarization  
✅ **Without Fine-Tuning**: Uses pre-trained models for general text summarization  
✅ Utilizes NLP libraries like `NLTK`, `spaCy`, `Transformers`  
✅ Works with various text formats  
✅ Jupyter Notebook implementation for easy experimentation  


### **Usage**  
1. **Provide an input text document.**  
2. **Choose the summarization technique:**  
   - **Extractive:** Selects key sentences from the text  
   - **Abstractive:** Generates a new summary while maintaining the meaning  
3. **Select Model Type:**  
   - **Without Fine-Tuning:** Uses pre-trained models (e.g., `BART`, `T5`)  
   - **With Fine-Tuning:** Fine-tuned on domain-specific data for better accuracy  
4. **Run the notebook to generate summaries.**
